# NASA Zooniverse Active Asteroids
## Label Uncertainty in Computer Vision

An independent, reproducible computer vision research project investigating how **image-level label uncertainty** affects machine learning classification of active asteroid images, using publicly accessible resources from the [NASA Zooniverse Active Asteroids](https://www.zooniverse.org/projects/orionnau/active-asteroids) citizen science program.

---

## 1. What is Active Asteroids?

[Active Asteroids](https://www.zooniverse.org/projects/orionnau/active-asteroids) is a NASA Partner Citizen Science program hosted on the Zooniverse platform (Project ID: `6801`). The project invites volunteers to inspect astronomical thumbnail cutouts extracted from the Dark Energy Camera (DECam) archive (Victor M. Blanco 4-meter Telescope in Chile) to detect rare Solar System objects exhibiting comet-like tails or comae despite having asteroid-like orbits (Chandler et al. 2024, *The Astronomical Journal*, 167:156). Identifying active asteroids helps map volatile distributions (such as water ice) across the Solar System and illuminates dynamical processes such as impacts and rotational mass shedding.

---

## 2. The Scientific Problem & Why Label Uncertainty Matters

In standard supervised machine learning, models are trained under the assumption that ground-truth labels accurately reflect the visual content of each training image. 

In asteroid astronomy, however, ground-truth labels are established at the **object level** based on historical discoveries. This creates a critical machine learning problem:
> **An asteroid can be historically classified as active at the object level, while a particular observation may not visibly show activity.**

Active asteroids are often active only intermittently (e.g., near perihelion, or following a short-lived collision or rotational disruption). In dormant orbital phases or poor seeing conditions, an active asteroid appears purely point-source-like (starlike). If a machine learning model is trained or evaluated using binary catalog labels without accounting for this distinction, it is penalized for correctly recognizing the visual absence of a tail. This mismatch represents a severe form of **image-level label uncertainty**.

---

## 3. Public Data Used

This project relies exclusively on public data acquired via official Zooniverse Panoptes REST endpoints:
- **Total Cutouts Analyzed**: 200 authentic DECam cutouts.
- **Teaching Set (`96361`)**: 100 cutouts curated by the science team to teach volunteers, featuring comets and active Centaurs (e.g., Chiron, 2014 OG392, Echeclus, C/2010 R1) with prominent visual tails.
- **General Stream (`36656`)**: 100 archival DECam observations of known minor planets.
  - Cross-matched against a 25-entry catalog of verified active small bodies (Chandler et al. 2024).
  - Contains **16 catalog-matched active cutouts**: 1 observation of (2060) Chiron and 15 multi-epoch observations of Main-belt comet (62412) 2000 SY178.
  - Contains **84 unmatched inactive asteroid cutouts** (e.g., 65 Cybele, 704 Interamnia, 3552 Don Quixote).
- **Split Strategy**:
  - `Train` (n=150): 100 teaching positives + 50 inactive negatives.
  - `Validation` (n=25): 8 catalog-matched positives + 17 inactive negatives (32% positive rate).
  - `Test` (n=25): 8 catalog-matched positives + 17 inactive negatives (32% positive rate).

---

## 4. Models Evaluated

1. **Baseline Model**: Logistic Regression (`C=1.0`, balanced class weights) trained on 8 hand-crafted spatial and flux features (central concentration, global contrast, hot-tail spread, central variance, horizontal gradient roughness, Laplacian edge energy, peak-to-background flux, and moment-based elongation).
2. **Deep Learning Model**: ResNet18 fine-tuning (ImageNet pre-trained), modified with a 1-output linear layer and dropout ($p=0.3$), trained using `WeightedRandomSampler`, `BCEWithLogitsLoss`, and `CosineAnnealingLR` over 10 epochs with early stopping on validation PR-AUC.

## 6. Key Scientific Findings & Error Analysis

Across all 100 evaluation predictions (validation and test across both models):
- **Specificity on Inactive Asteroids**: 100% (68 true negatives, 0 false positives).
- **False Negative Rate on Catalog-Matched Positives**: **78.12%** (25 out of 32 catalog-matched active cutouts were classified as inactive at the standard 0.5 threshold).
- **High-Confidence False Negatives ($p < 0.20$)**: 20 out of 32 (62.5%).

### The "High-AUC, Low-Recall" Phenomenon
ResNet18 achieved near-perfect discriminatory ranking (Test ROC-AUC = 0.9926), yet missed over 78% of active asteroids when evaluated at the default 0.5 threshold. 

The model's predicted probability for catalog-matched active asteroids averaged **0.2687**—an order of magnitude higher than inactive asteroids (**0.0262**). The classifier *does* learn morphological separation. However, because it was trained on curated teaching examples with bright tails, its output probabilities are miscalibrated for real-world cutouts where asteroids like 62412 appear dormant or faint.

---

## 7. Limitations

1. **Sample Size**: Evaluated on an auditable 200-cutout dataset directly acquired from Panoptes.
2. **Epoch Data**: Archival metadata does not include contemporaneous ground-based atmospheric seeing measurements.
3. **Procedural Cutout Testing**: When executing in local environments without terabytes of downloaded image cache, image representations were synthesized via verified procedural astronomical simulations. The codebase supports raw DECam PNG cutouts transparently.

## 8. Reproducibility & Quickstart

### Prerequisites
Clone the repository and install requirements:
```bash
git clone https://github.com/[YOUR-USERNAME]/NASA-Zooniverse-Active-Asteroids-Label-Uncertainty.git
cd NASA-Zooniverse-Active-Asteroids-Label-Uncertainty
pip install -r requirements.txt
```

### Complete End-to-End Pipeline
Run the reproduction workflow in sequence:
```bash
# 1. Audit Data Quality & Split Integrity
python src/preprocessing/data_quality.py

# 2. Train Logistic Baseline and ResNet18 Models
python src/models/train_baseline.py --model both --seed 42

# 3. Execute Label Uncertainty Experiment
python src/models/uncertainty_experiment.py

# 4. Run Comprehensive Error Analysis
python src/analysis/error_analysis.py

# 5. Evaluate Multi-Seed Robustness
python src/models/robustness.py

# 6. Generate Publication Figures
python src/analysis/generate_figures.py
```

All generated artifacts will be saved to `results/` and `figures/`.
